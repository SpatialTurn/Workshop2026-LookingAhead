# Looking Ahead

Source for the **Looking Ahead** module of the [Workshop 2026](https://spatialturn.github.io/workshop2026.html) materials, part of [Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/).
Published at <https://spatialturn.github.io/Workshop2026-LookingAhead/>.

Designing and building your own geospatial teaching module as a Carpentries-style lesson (Markdown basics, creating a lesson repository from the Workbench template, working with GitHub Desktop, and adding episodes), with additional readings on data curation, FAIR data, metadata and data sharing.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/).
It is kept as it was taught at the workshop (Day 2, Putting it all Together, for all participants).
